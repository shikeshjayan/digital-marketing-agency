### 68: Admin Column Height Fix & Icon Sweep (Technologies/Industries)

#### Fix C: Modal Centering (Session 73c)

**Root cause:** `@keyframes page-fade-in` in `index.css:209-218` used `transform: translateY(8px)`. With `animation-fill-mode: both`, the `transform: translateY(0)` persists after animation, creating a new containing block. **Fix:** Removed `transform` from `@keyframes page-fade-in` (opacity-only fade remains). One CSS change fixes all modals site-wide (ConfirmModal, logout dialog, etc.).
