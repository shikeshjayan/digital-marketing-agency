# AI Context — Digital Marketing Agency Platform

## Project Overview

- **Type:** Full-stack digital marketing agency website
- **Stack:** React 19 + Vite + Tailwind CSS (frontend), Node.js/Express + MongoDB (backend)
- **Routing:** react-router-dom v7 (BrowserRouter API)
- **State:** Zustand stores, no Redux
- **UI:** FontAwesome icons, custom components, no UI library

## Model Schemas — Quick Reference

### Service (Session 47)
```
service_name, slug (unique), short_description, description, hero_image, icon,
deliverables ([String]), benefits ([String]), featured (Boolean), display_order (Number),
seo ({ meta_title, meta_description }), status (Active/Inactive), timestamps
```

### Project
```
project_name, slug (unique, auto-generated), short_description (required, maxlength 200),
description (required), thumbnail (required), gallery ([String]),
services ([ref: Services], required), technologies ([ref: Technology]),
industries ([ref: Industry]), team ([ref: Team]),
client ({ name, company, website, location }),
project_url, github_url, completion_date, featured (Boolean),
seo ({ meta_title, meta_description }), status (Draft/Published), timestamps
```

### CaseStudy (Session 48)
```
title, slug (unique), project (ref: Projects, unique), hero_image, overview, challenge,
objectives ([String]), strategy, solution, deliverables ([String]),
timeline ({ duration, started_at, completed_at }),
development_process ([{ title, description }]),
challenges_and_solutions ([{ challenge, solution }]),
results ([{ title, value }]), gallery ([String]),
client_testimonial ({ quote, client_name, designation, company }),
featured (Boolean), seo ({ meta_title, meta_description }), status (Draft/Published), timestamps
```

### FAQ (Session 52)
```
question, answer, service (ref: Services), display_order (Number),
status (Active/Inactive), timestamps
```

### Technology
```
name (unique), slug (unique, auto-generated), description, icon,
display_order (Number), status (Active/Inactive), timestamps
```

### Industry
```
name (unique), slug (unique, auto-generated), description, icon,
display_order (Number), status (Active/Inactive), timestamps
```

### Team
```
photo, name (required), designation (required), description,
linkedin, email, display_order (Number), status (Active/Inactive), timestamps
```

### Review
```
user_avatar (SVG placeholder default), name (required), location (required),
rating (1-5, required), review_text (required),
status (Pending/Approved/Rejected), timestamps
```

### Contact
```
name (required), email (required, lowercase), phone, service (String),
message (required), status (New/Pending/Replied/Spam), timestamps
```

### Admin
```
name (required), email (required, unique, lowercase), password (required, minlength 6, select: false),
photo, role (default: "admin"), timestamps
Password auto-hashed via bcrypt pre("save") hook.
```
